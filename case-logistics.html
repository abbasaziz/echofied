The Automation Workflow

  1. Trigger: Samsara sends a webhook that Truck #42 has dropped its load and is now empty.
  2. Action: Echofied agent queries McLeod TMS for available backhauls within a 50-mile radius.
  3. Match: Agent finds a load matching the driver's HOS (Hours of Service) and weight capacity.
  4. Approval: Agent sends a Slack message to the dispatcher: "Match found: Load #8821. Approve?"
  5. Execution: Dispatcher clicks "Approve". Agent writes the assignment to McLeod and sends an SMS to the driver with the new route.
